# Player de Música

**Descrição**: Um aplicativo mobile para reprodução de músicas com controle de play, pause e navegação entre faixas.

## Tecnologias
- Frontend: React Native
- Backend: Java (Spring Boot)
- Banco de Dados: PostgreSQL

## Instalação
```bash
git clone https://github.com/Brettas2602/Player-de-musica.git
cd Player-de-musica
# frontend
cd mobile
npm install
npm start
```

Para configurar o backend, será necessário configurar as variáveis de ambiente do banco de dados postgres no ```application.properties```. Em seguida, executar o método main em ```ProjetoFinalApplication.java```
